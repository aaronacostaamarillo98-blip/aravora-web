# aravora — psicología con evidencia, convertida en herramientas simples

Sitio web de **aravora**, mi estudio de productos digitales. Presenta la colección de guías interactivas *«¿Por qué…?»* y **alvora**, una página para encontrar al psicólogo que encaje con cada persona.

🔗 **Sitio en vivo:** https://aaronacostaamarillo98-blip.github.io/aravora-web/

## Qué incluye

- **Landing de la colección «¿Por qué…?»:** tres guías basadas en psicología con evidencia (ansiedad, cansancio y sueño), con vista previa de páginas y packs.
- **alvora** (`alvora.html`): página para orientar a las personas a encontrar al psicólogo adecuado.
- Páginas de **privacidad** y **términos**.
- Imágenes optimizadas en WebP y tarjetas para compartir en redes (Open Graph).
- Medición de campañas con el píxel de Meta.

## Tecnología

HTML, CSS y JavaScript sin frameworks, publicado en GitHub Pages. Diseño propio, responsive, con tipografías de Google Fonts. Desarrollado con asistencia de IA (Claude).
